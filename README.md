# Sweet Bakery — GitHub Pages version

This is the static version of Sweet Bakery for GitHub Pages.

## Publish from your phone
1. Create a GitHub repository.
2. Upload everything in this folder to the repository root.
3. Open Settings → Pages.
4. Under Build and deployment, choose Deploy from a branch.
5. Select `main` and `/ (root)`, then Save.
6. Wait a few minutes for the site to publish.

## WhatsApp
Open `app.js` on GitHub and replace the empty `WHATSAPP_NUMBER` value with the bakery's WhatsApp number in international format, digits only.

Example: `23324XXXXXXX`

This GitHub Pages version does not use the Node/Express backend because GitHub Pages is static hosting.
