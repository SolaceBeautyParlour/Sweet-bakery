# Healthy Oven Bakery — GitHub Pages

A responsive static website for Healthy Oven Bakery in Sakumono, Ghana.

## Included
- Vibrant orange premium bakery design
- Responsive mobile/desktop layout
- Cakes, cupcakes, pastries, bread, cookies and desserts
- Custom-order form
- WhatsApp order handoff with the full form details pre-filled in the WhatsApp chat
- Google Maps link
- Public business details integrated where verified

## Publish on GitHub Pages
1. Create a public GitHub repository.
2. Upload all files in this folder to the repository root.
3. Settings → Pages → Deploy from a branch → `main` → `/ (root)` → Save.

## Important
This is a static GitHub Pages site. It does not require Node.js or a database. Product photos are loaded from external image URLs, so an internet connection is required for those images.
